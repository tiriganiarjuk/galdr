# Field audit — long form, by section

Generated by `probe/field_audit.py`. Per section: the data shape, the
bundles the real bundler produces, what the review document already says,
and then every field that needs a decision — with its stated purpose, what
its name actually addresses, and a tentative fix where one is derivable.

The control surfaces were largely authored by agents that did not know what
the bundler and resolver would have to do with the names, so a plausible
name is not evidence that it works. Two sources carry intent: the Verdandi
field definition says what the field is for, and `review/{SECTION}.md` says
what it is meant to control. A field marked OK there and flagged here is
not a contradiction — that document checked slot assignment, this checks
whether the name declares it.
